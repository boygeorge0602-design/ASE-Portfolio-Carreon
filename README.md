# ASE-Portfolio-Carreon

## Course Introduction
**CPELX230-330 — Term 2 2026–2027: Exploring Agentic Software Engineering and Responsible AI**

This course explores how modern software engineering practices evolve when building AI-powered agentic systems. It bridges traditional software engineering principles, Agile workflows (Scrum), distributed version control (Git), intelligent agent architecture, and risk governance frameworks such as the NIST AI Risk Management Framework.

## Personal Learning Goals
- Understand how autonomous and semi-autonomous AI agents differ from deterministic traditional software systems.
- Apply Agile iteration (transparency, inspection, and adaptation) and clean Git version control workflows to evolving AI-enabled projects.
- Identify key operational, security, and ethical risks in agentic applications and design appropriate human-in-the-loop guardrails.
- Build reliable, well-documented software engineering artifacts that prioritize safety, privacy, and accountability.

## Reflection from Part A
Analyzing Agentic Software Engineering highlighted that shifting from traditional rule-based software to goal-directed AI agents changes how systems must be engineered and governed. Because AI agents perceive environments, reason probabilistically, and execute actions through tools, rigid upfront specifications are insufficient, making iterative Agile development and disciplined version control essential. Most importantly, autonomy does not remove human accountability; strong risk management and human oversight remain critical to prevent unintended behavior and ensure safe, responsible deployment.
